# VEXSSH downloads

Choose **Installer** to install or update VEXSSH on Windows x64. Choose **Portable** to run it directly with WebView2 already installed. Versions marked `rc` are release candidates.

## 1.0.0-rc.11 · Latest download

26 November 2026

- Save received Serial output to a local log with a UTC timestamp on each line. Use **Record log** to start and **Stop recording** to finish.
- Set separate upload and download limits in **Settings → File transfer**. Active SFTP transfers share the limit for their direction. Save a new value to apply it immediately, or use `0` for unlimited speed.

## 1.0.0-rc.10

26 November 2026

## 1.0.0-rc.9

26 November 2026

- Choose from five new terminal palettes: Midnight, Graphite, Paper, Forest, and Dusk. JetBrains Mono and IBM Plex Mono are bundled for offline use.
- Set the font and default text color for SSH and Serial in **Settings → Terminal**. SSH profiles can override the default color, and programs keep their ANSI colors.
- Drop folders onto the remote SFTP path field. Terminal, Files, and Serial are now grouped together in the sidebar.
